Como usr_qasailpoint, en tu sesión actual. Prueba el DC de siempre y el segundo, porque el Global Catalog de la app es PMDC003:

powershell
$dn = "CN=slunam,OU=Aguascalientes,OU=Foraneos,OU=Usuarios,DC=dombase,DC=net"
foreach ($dc in "MTY-ALE-PMDC002.dombase.net","MTY-ALE-PMDC003.dombase.net") {
  try { $e = [ADSI]"LDAP://$dc/$dn"; $e.Put("lockoutTime",0); $e.SetInfo(); "OK     usr_qasailpoint en $dc" }
  catch { "ERROR  usr_qasailpoint en $dc : " + $_.Exception.Message }
}

Como usrsailqa, tecleando el password en el diálogo:

powershell
$c = Get-Credential dombase\usrsailqa
foreach ($dc in "MTY-ALE-PMDC002.dombase.net","MTY-ALE-PMDC003.dombase.net") {
  try { $e = New-Object System.DirectoryServices.DirectoryEntry("LDAP://$dc/$dn", $c.UserName, $c.GetNetworkCredential().Password); $e.Put("lockoutTime",0); $e.SetInfo(); "OK     usrsailqa en $dc" }
  catch { "ERROR  usrsailqa en $dc : " + $_.Exception.Message }
}

Es inocuo: escribe lockoutTime = 0 en tu propia cuenta, que ya está desbloqueada.
