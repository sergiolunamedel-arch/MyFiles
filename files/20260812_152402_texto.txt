El Flow (o Workflow) atado a este catalog item casi con certeza tiene una condición explícita tipo "self-service": compara el valor de esas variables del solicitante contra la identidad real del usuario autenticado que hace la llamada a la API (gs.getUserID() / gs.getUserName() / el campo requested_for), y:

Si coinciden (estás pidiendo "para ti mismo") → salta aprobación, no crea tareas, y cierra el REQ como Closed Complete de inmediato.
Si NO coinciden (pides "a nombre de otra persona", como con Yessica) → sigue el camino normal: queda abierto pendiente de aprobación/tareas.

Esto es un patrón bastante común y documentado en instancias de ServiceNow ("solicitudes para uno mismo se auto-aprueban/auto-completan").
