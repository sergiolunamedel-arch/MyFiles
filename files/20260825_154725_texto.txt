1
Abrir la configuración del plugin
En IntelliJ, ve a File > Settings (o Preferences en macOS) > Tools > Snyk. Ahí es donde vive toda la configuración de autenticación del plugin, incluyendo el método usado (OAuth 2.0, Personal Access Token o API token).
2
Vaciar el campo Token
Dentro de esa pantalla verás un campo llamado 'Token'. Selecciona todo su contenido y bórralo, dejándolo completamente vacío. Esto aplica sin importar si la sesión se hizo con OAuth o con un token manual — internamente el plugin guarda la credencial activa ahí.
3
Aplicar y cerrar
Haz clic en Apply y luego en OK. En ese momento el plugin queda desconectado: ya no podrá lanzar escaneos hasta que se vuelva a autenticar.
4
Reiniciar el flujo de autenticación
Haz clic en el icono de Snyk en la barra lateral/inferior y selecciona 'Trust project and scan' (o el botón 'Connect IDE to Snyk' si usas PAT/API token). Se abrirá el navegador para iniciar sesión desde cero — ahí es donde el usuario debe entrar con las credenciales de la cuenta correcta antes de autorizar el acceso.
5
Verificar que quedó ligado a la organización correcta
Una vez autenticado, confirma en la misma pantalla de Settings > Tools > Snyk (o en el panel de resultados del escaneo) que el proyecto está asociado a la organización de Banco Base y no a una organización personal. Si Snyk permite elegir Organization ID explícitamente, verifícalo también ahí, porque una cuenta puede tener acceso a varias organizaciones.
